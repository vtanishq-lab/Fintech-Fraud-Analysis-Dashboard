# Fintech Fraud Analysis | Power BI Dashboard

## 📊 Project Overview

This project focuses on analyzing fintech transaction data to identify fraud patterns, customer risk, transaction behavior, and age-group trends.
An interactive Power BI dashboard was created to transform transaction data into meaningful business insights and support data-driven fraud and risk management decisions.

## 🎯 Project Objectives

- Analyze overall transaction activity
- Monitor fraud rate
- Identify fraud patterns across age groups
- Analyze customer risk levels
- Understand transaction types and payment behavior
- Analyze failed login attempts
- Compare credit scores across age groups
- Identify potentially high-risk customer segments

## 🔑 Key KPIs

| KPI | Value |
|---|---:|
| Customer Count | 64K |
| Total Transaction Amount | 232M |
| Fraud Rate | 13% |
| Foreign Transaction Rate | 10% |
| Average Credit Score | 736 |
| Average Risk Score | 13 |

## 🔍 Key Insights

- Senior Adults (46–60) have the highest fraud count among the displayed age groups.
- Senior Adults also have the highest 30-day transaction activity.
- Failed login attempts are highest among Senior Adults.
- UPI is the most frequently used transaction type, representing 50% of transactions.
- Foreign transactions account for 10% of transaction activity.
- Fraud and credit-score patterns vary across different age groups.
